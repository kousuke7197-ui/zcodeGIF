gif-mouse-follower

GIF 鼠标跟随自定义工具

上传你喜欢的 GIF，或选择内置可爱预设，让它以柔和、轻盈的动画跟随鼠标移动。 所有设置都会自动保存在本机浏览器中，刷新后也能恢复。

移动鼠标即可预览效果
01

平滑跟随

使用 requestAnimationFrame 实现缓动跟随，GIF 位于最上层且不会阻挡页面点击。

02

自由定制

支持上传本地 GIF，调整大小、偏移、透明度，并可一键切换预设。

03

即开即用

纯静态单页项目，无框架、无依赖、无后端，天然适配 GitHub Pages。
